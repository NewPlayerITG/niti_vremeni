# Нити времени — прототип (веб, формат телефона)

Глава 1 («Гжель») на ваших иллюстрациях. Чтобы пройти уровень, достаточно выполнить **любое одно из трёх заданий**:

1. **Пазл 5 × 5** — 25 кусочков узора. Коснитесь двух кусочков, и они поменяются местами; верные кусочки закрепляются и «сливаются» с картинкой. Есть «Образец». **При повторном прохождении показывается другая картинка.**
2. **Найди пару** (карточки-запоминалки) — переворачиваете две карточки: совпали — исчезают, нет — переворачиваются обратно. На трёх уровнях главы **4, 5 и 6 пар**. При каждой игре набор и расклад карточек новые; при совпадении Клубочек рассказывает, что это за элемент росписи.
3. **Раскраска** — ваза, чайник и плитки раскрашиваются оттенками кобальта (4 оттенка + ластик). Есть «Образец мастера» и «Увеличить» для мелких областей. При повторе — другое изделие.

Остальные задания уровня можно пройти позже ради бонусных искорок. Уровней в главе 1 — три.

## Запуск

Нужен Python 3.10+.

    python -m venv .venv
    # Windows:     .venv\Scripts\activate
    # macOS/Linux: source .venv/bin/activate
    pip install -r requirements.txt
    python app.py

Откройте http://localhost:5000. С телефона в той же Wi-Fi сети — `http://<IP компьютера>:5000`.

Переменные окружения (необязательно): `PORT`, `HOST` (по умолчанию `0.0.0.0`; для доступа только с этого компьютера — `127.0.0.1`), `NITI_SECRET` (ключ подписи cookie), `NITI_DATA` (папка с прогрессом), `NITI_DEBUG=1` (отладка; включайте только локально).

Проверка без браузера: `python test_game.py`.

Интернет нужен только для шрифтов Google Fonts; без него игра работает с запасными шрифтами.

## Где что лежит
- `content.py` — все данные: главы, уровни (какой пазл, какие карточки, какая раскраска), тексты карточек, оттенки, награды, магазин.
- `logic.py` — правила: открытие уровней, три задания, звёзды, награды (каждая выдаётся один раз), подсказки, покупки.
- `app.py` — Flask: страница и JSON-API. Прогресс игроков — JSON-файлы в `instance/players/`, в cookie только подписанный идентификатор.
- `templates/index.html`, `static/style.css`, `static/app.js` — интерфейс.
- `static/img/patterns/p1..p8.png` — 8 узоров для пазлов (нарезаны из первого вашего изображения).
- `static/img/motifs/m1..m8.png` — 8 карточек для игры «Найди пару» (из второго изображения).
- `static/img/color/*.json` — области раскрасок (векторные контуры), `*_ref.png` — «образец мастера».
- `data_private/` — эталонные оттенки раскрасок. **В браузер не отдаются** (в `static/` их нет).
- `src_img/` и `tools/` — исходные картинки и скрипт, который всё нарезает и готовит раскраски.

## Как устроены правила
- **Звёзды:** 3 — без ошибок и подсказок, 2 — не больше двух ошибок/подсказок в сумме, иначе 1. В «Найди пару» звёзды считаются по промахам: не больше, чем пар, — 3 звезды; не больше удвоенного числа пар — 2; больше — 1 (подсказки тоже учитываются). В раскраске звёзды ограничены ещё и совпадением с образцом мастера: от 80 % — до 3 звёзд, от 60 % — до 2, ниже — 1 (соседний оттенок засчитывается наполовину).
- **Подсказка (30 искорок):** в пазле ставит один кусочек на место; в «Найди пару» на 1,6 секунды показывает одну пару; в раскраске подсказывает оттенок для самой крупной неверной области.
- **Награды:** база за первое прохождение уровня; +20 за каждое другое задание того же уровня (один раз); +15 «доп. цель» и +10 «три звезды» (один раз на уровень); +50 за главу. Все числа — в начале `content.py`.
- Если выйти из задания и зайти снова, счётчик ошибок и подсказок сохраняется (его нельзя «обнулить»).

## Как добавить уровень
В `LEVELS` (`content.py`) добавьте запись: номер `n`, `puzzle.images` (картинки из `static/img/patterns`: первая — для первого прохождения, остальные — для повторов), `memory.pairs` (число пар, не больше 8) и `color.names` (раскраски). Для награды добавьте число в `REWARD_BASE`.

Новая раскраска: положите картинку в `src_img`, добавьте её в словарь `COLOR` в `tools/make_assets.py` и в `CERAMICS` в `content.py`, затем `pip install -r tools/requirements-tools.txt && python tools/make_assets.py`.

## Что я решил сам (поправьте, если нужно по-другому)
- Пазл — «обмен кусочков касанием», а не перетаскивание: так удобнее на телефоне. Узоры с повторами (лилии, ряды цветов) в пазлы не брал: кусочки у них неотличимы.
- Раскраски получены автоматическим разбиением ваших акварельных иллюстраций на области по четырём оттенкам, поэтому границы областей повторяют контуры мазков.

## Безопасность
Файл `_secret_key` из прошлой версии больше не используется: ключ создаётся сам в `instance/secret_key`. Если старый ключ где-то публиковался, считайте его скомпрометированным.

## Перед выпуском
Исторические справки (`ATLAS_PAGES`) и тексты справок к карточкам (`CARDS`) нужно проверить по источникам.
